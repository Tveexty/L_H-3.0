# Launcher Hab 3.0 & Luma Core 1.0 (C# .NET 8 Edition)

Полный рерайт модульного десктопного лаунчера **Launcher Hab 3.0** и фонового ядра **Luma Core 1.0** на язык **C# (.NET 8 / WPF / WASAPI / AES-256-GCM)**.

## Ключевые изменения в версии 3.0
1. **Переход на C# (.NET 8) и релизное ядро Luma 1.0**:
   - Фоновый демон `LumaCoreDaemon.cs` работает в Headless-режиме на `127.0.0.1:49215` по протоколу JSON-RPC 2.0.
   - Потребление ОЗУ снижено за счет строго типизированного пула памяти .NET 8 и асинхронных сокетов.
2. **Обновленная безопасность ядра (Luma Security 1.0)**:
   - Шифрование конфигураций и секретов переведено на **AES-256-GCM** (96-бит Nonce + 128-бит AuthTag).
   - Деривация ключей усилена до **PBKDF2-HMAC-SHA512 (310 000 итераций)**.
   - Все IPC-сообщения между UI и ядром подписываются **HMAC-SHA256** с защитой от Replay-атак (окно 30 сек).
3. **Плиточный главный экран 3.0 + Переключатель в Классический Быстрый Поиск**:
   - **Основной экран плиток (Tile Grid 3.0)**: живые плитки в стиле Windows 11 / Windows Phone / iOS с возможностью свободного перемещения (вверх/вниз/перетаскивание), выбора колонок и закрепления приложений, папок и 12 виджетов прямо на домашнем экране.
   - **Быстрый поиск (Старое окно)**: сохранен переключатель в шапке лаунчера для мгновенного возврата к классическому окну с боковой панелью, категориями и поиском.
4. **Создание папок и настройка размеров (1x1, 2x1, 2x2)**:
   - Создание пользовательских папок, добавление/удаление приложений внутри папки, переименование и выбор цвета папки.
   - Изменение размера для **Папок** (`1x1`, `2x1`, `2x2`), **Иконок приложений** (`1x1`, `2x1`, `2x2`) и **Виджетов** (`1x1`, `2x1`, `2x2`).
5. **12 интерактивных системных виджетов Luma 1.0**:
   - `2x1` Системный монитор (CPU / RAM) с цветовой индикацией (зеленый/желтый/красный)
   - `2x1` Анализатор накопителей (Диски C: и D:) в ГБ и %
   - `1x1` Аудио-микшер и громкость (ползунок, Mute, активное устройство)
   - `2x2` Быстрые заметки и To-Do (интерактивный чек-лист, зачеркивание, быстрый ввод)
   - `1x1` Часы, дата и системный аптайм (секунды, день недели, счетчик аптайма)
   - `2x1` Быстрый запуск утилит (Терминал/CMD, Диспетчер задач, Редактор реестра, Проводник)
   - `1x1 / 2x1` Сетевой монитор (Network I/O — входящий/исходящий трафик КБ/с и МБ/с)
   - `2x1` Медиаплеер (Now Playing — Play/Pause, След/Пред, название трека)
   - `1x1` Таймер / Помидор (Pomodoro Focus — 25/5 мин, Старт/Пауза/Сброс, звуковой сигнал)
   - `1x1 / 2x1` Погода и температура за бортом (реальный поиск любого города мира через Open-Meteo Geocoding + Forecast API, почасовой прогноз)
   - `2x1` Быстрый калькулятор / Конвертер (мгновенные вычисления и конвертация валют/единиц)
   - `1x1` Управление питанием системы (Сон, Перезагрузка, Блокировка экрана Win+L, таймер автовыключения)
6. **Plugin API v3.0 (C#)**:
   - Интерфейс `ILumaPluginV3`, песочница разрешений, регистрация собственных плиток на главном экране и шифрованное хранилище секретов.
