# Luma Oxygen Connect 1.7.1 — Android Companion App (HarmonyOS Wave & 1-Tap UI)

Официальное мобильное приложение-компаньон **Luma Oxygen Connect** для **Luma OS 1.7.1 (Oxygen · O-8)** в стиле Cryo-Glass Oxygen.

## Как подключиться к ПК за 3 секунды (без проводов и без сборки APK)
1. Откройте на ПК **Luma OS 1.7.1 → Oxygen Connect (Android)**.
2. Наведите камеру Android-смартфона на **QR-код** (оба устройства в одной Wi-Fi сети).
3. Откроется максимально простой 1-экранный интерфейс **Luma Oxygen Connect** — нажмите в браузере «Добавить на главный экран», чтобы установить его как полноценное приложение с иконкой O₂!

## Сборка нативного APK в Android Studio
Эта папка содержит готовый проект на **Kotlin** (`MainActivity.kt` + `AndroidManifest.xml` + `build.gradle.kts`) с нативным доступом к камере, выбору файлов и автоматическим сохранением IP/PIN вашего ПК:
1. Откройте папку `LumaOxygenConnect_Android` в **Android Studio (Ladybug / Jellyfish+)**.
2. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Установите собранный APK на телефон и отсканируйте QR или введите IP и 6-значный PIN из **Luma OS 1.7.1**.

## Что нового в 1.7.1
- 🌊 **Полноэкранная волна HarmonyOS:** при каждой отправке и приёме файлов по всему экрану смартфона и ПК расходится светящаяся круговая волна с тактильной вибрацией и звуком.
- 📱 **Ультра-простой 1-тап интерфейс:** никаких лишних вкладок — все 4 главные кнопки (**«📸 Фото на ПК»**, **«📁 Файл на ПК»**, **«🔍 Circle to Search»**, **«📋 Общий буфер»**), входящие файлы с ПК, тачпад и громкость/медиа прямо на одном экране.
- 🖱️ **Ускоренный плавный тачпад (`1.4×` по умолчанию):** адаптивное ускорение указателя, частота `14 мс`, переключатель скорости `1.0× / 1.4× / 2.0×`, тап двумя пальцами (ПКМ) и плавный скролл двумя пальцами.
- 🔍 **Полноценный Circle to Search прямо на телефоне:** обведите пальцем область на **фото с камеры** или на **живом экране ПК** — мгновенный структурированный разбор (товар/бренд, текст + перевод на русский, причина и фикс ошибки, место, пошаговая математика).
