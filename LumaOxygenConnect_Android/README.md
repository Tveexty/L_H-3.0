# Luma Oxygen Connect — Android Companion App (HarmonyOS SuperHub Ecosystem)

Официальное мобильное приложение-компаньон **Luma Oxygen Connect** для **Luma OS 1.7 (Oxygen · O-8)** в стиле Cryo-Glass Oxygen.

## Как подключиться к ПК за 3 секунды (без проводов и без сборки APK)
1. Откройте на ПК **Luma OS 1.7 → Oxygen Connect (Android)**.
2. Наведите камеру Android-смартфона на **QR-код** (оба устройства в одной Wi-Fi сети).
3. Откроется мобильное приложение **Luma Oxygen Connect** — нажмите в браузере «Добавить на главный экран», чтобы установить его как полноценное приложение с иконкой O₂!

## Сборка нативного APK в Android Studio
Эта папка содержит готовый проект на **Kotlin** (`MainActivity.kt` + `AndroidManifest.xml` + `build.gradle.kts`) с нативным доступом к камере, выбору файлов и автоматическому сохранению IP/PIN вашего ПК:
1. Откройте папку `LumaOxygenConnect_Android` в **Android Studio (Ladybug / Jellyfish+)**.
2. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. Установите собранный APK на телефон и отсканируйте QR или введите IP и 6-значный PIN из **Luma OS 1.7**.

## Возможности (HarmonyOS SuperHub / Device+)
- 📸 **Камера → ПК мгновенно:** сфотографируйте документ или предмет — снимок сразу прилетает в Luma Drop Shelf и `Downloads/OxygenConnect`.
- 📁 **Двусторонняя передача файлов:** кидайте пачки файлов с телефона на ПК и скачивайте файлы с Рабочего стола / Полки / Загрузок ПК на телефон.
- 📋 **Общий буфер обмена (Телефон ↔ ПК):** отправка и получение текста/ссылок в 1 нажатие.
- 🖱 **Виртуальный тачпад и клавиатура ПК:** управляйте курсором, кликами, скроллом и вводите текст на ПК прямо с экрана смартфона.
- 🎵 **Медиа-пульт, громкость и живая телеметрия ПК** (CPU / RAM / Звук / быстрый запуск программ / блокировка ПК).
