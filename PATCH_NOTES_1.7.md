# Luma OS 1.7 (Oxygen · O-8) — Patch Notes

**Версия ПО:** `1.7 (Oxygen · O-8)`  
**Версия ядра:** `LumaCore 1.6.0`  
**Антивирус:** `LumaShield 3.2 (Zero-Freeze · 340+ правил)`  
**Исполняемый файл:** [`LumaOS_1.7.exe`](LumaOS_1.7.exe) (единый портативный x64 Windows PE32+ GUI-бинарник, все 27 предыдущих сборок сохранены)

> [!WARNING]
> **Важное предупреждение о старых версиях:** сборки **1.6.4 – 1.6.6b** имеют нестабильную работу — **не используйте их**. Для стабильной работы используйте актуальную версию **Luma OS 1.7 (Oxygen)** (или финальную сборку ветки 1.6.x — `LumaOS_1.6.7.exe`).

## Что нового и исправлено в Luma OS 1.7 (Oxygen · O-8)

### 1. 100% прогрузка всех иконок приложений и файлов
- Полностью исправлен баг, когда часть иконок на рабочем столе, в папках или в списке программ не прогружалась.
- В `LumaCore 1.6.0` для потока извлечения иконок добавлена STA COM-инициализация (`runtime.LockOSThread()` + `CoInitializeEx(COINIT_APARTMENTTHREADED)`), резервный вызов `ExtractIconExW`, чтение системных иконок расширений (`SHGFI_USEFILEATTRIBUTES`) и расширенная карта псевдонимов (Discord `app-*`, Telegram, VS Code, Office, Steam, Spotify, Chrome/Edge/Opera/Brave/Yandex, OBS, Notion, GitHub и др.).
- Маршрут `/api/kernel/app-icon` больше никогда не возвращает `HTTP 404` — при отсутствии бинарника мгновенно генерируется чёткий 2.5D-значок Oxygen SVG; на фронтенде добавлены сброс старого кэша WebView2 (`?v=17`) и автоматический повтор загрузки.

### 2. Умный автозапуск самой новой версии после перезагрузки ПК
- Исправлен баг, из-за которого после перезагрузки компьютера могла запускаться старая версия Luma OS.
- При старте `LumaOS_1.7.exe` ядро автоматически сравнивает SemVer всех сборок `LumaOS_*.exe`, обновляет ключ автозапуска `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\LumaOS` на самую свежую версию (никогда не откатывая назад) и очищает устаревшие дубликаты/ярлыки в папке `Startup`.
- OTA-обновитель также сразу синхронизирует ключ автозапуска с вновь установленным файлом.

### 3. Продвинутый менеджер правил для окон (Window Rules · KWin)
- Новый раздел **Настройки → Правила окон (KWin)** с определением всех подключённых мониторов (`Win32 EnumDisplayMonitors`).
- Задайте правило один раз — и ядро автоматически применяет его к нужным программам:
  - Пример: *«всегда открывать Telegram на 2-м мониторе справа без рамки»*
  - Пример: *«Калькулятор всегда поверх всех окон»*
  - Пример: *«Игры — с автоотключением уведомлений (DND) и композитора размытия для максимального FPS»*
- Поддерживаются зоны (`Лево`, `Право`, `Четверти`, `Центр`, `Развернуть`, `Полный экран`), `Поверх всех окон`, `Без рамки`, прозрачность (40%–100%), готовые пресеты в 1 клик и фоновый мониторинг.

### 4. Навсегда починенный `Alt+Tab` при переходе с рабочего стола
- Полностью устранена проблема, из-за которой было невозможно нормально переключиться с рабочего стола Luma OS на Chrome, Telegram, игру или другое окно Windows:
  1. Снятие временного `HWND_TOPMOST` в `releaseAltTabTopmost()` переведено в **синхронный** режим без гонки `wv.Dispatch`.
  2. Маршрут `/api/kernel/windows/focus` теперь атомарно снимает TopMost и вызывает `FocusWindowWithHWND(pid, hwnd)` с полным стеком Win32 (`AllowSetForegroundWindow(ASFW_ANY)` + `AttachThreadInput` + `ShowWindow(SW_RESTORE)` + `BringWindowToTop` + `SetWindowPos(HWND_TOP)` + `SetForegroundWindow` + `SetActiveWindow`).
  3. При первом нажатии `Alt+Tab` с рабочего стола Luma OS выбор **всегда** сразу переходит на реальное окно (а не остаётся на рабочем столе).

### 5. Полка Drag & Drop (аналог Yoink / Dropzone · `Ctrl+Alt+S`)
- При перетаскивании любого файла, картинки, ссылки или текста у края экрана автоматически выезжает стеклянная **Полка Dropzone** (сторона экрана переключается `Лево ↔ Право`).
- Можно собрать сразу пачку файлов из разных папок, переключиться в другое окно или на другой виртуальный рабочий стол и забрать всё разом: **скопировать пачкой**, **переместить пачкой** в выбранную папку или **упаковать всю полку в один ZIP-архив**.

### 6. Умный буфер обмена с категориями и Auto-OCR (аналог Paste / Raycast · `Ctrl+Shift+V`)
- Новый стеклянный интерфейс умного буфера обмена с мгновенным поиском и вкладками: **Все**, **Закреплённые**, **Текст**, **Ссылки**, **Цвета** (с живыми цветовыми образцами HEX / RGB / HSL), **Картинки**, **Файлы** и **Код**.
- Встроенный **Auto-OCR для изображений** (нативный Windows `WinRT OcrEngine`) — распознаёт текст со скриншотов и картинок прямо из буфера в 1 клик.
- **Вставка чистого текста без форматирования (Plain Text)** включена по умолчанию.

### 7. Per-App Аудио-центр в выпадающей Панели управления (KDE Plasma / PipeWire)
- Прямо внутри выпадающей Панели управления (справа сверху / `Tab`) появился полноценный **Per-App микшер звука**:
  - Индивидуальные ползунки громкости и Mute для каждого запущенного приложения (Windows Core Audio `IAudioSessionManager2` / `ISimpleAudioVolume`).
  - **Drag & Drop перенаправление вывода**: перетащите карточку приложения на нужное устройство вывода (Наушники / Колонки / HDMI).
  - Индивидуальное управление каждым открытым плеером (`⏮ / ⏯ / ⏭`) и быстрый системный Mute микрофона.

### 8. Капсульные OSD-индикаторы нового поколения (Oxygen / Material You)
- Полупрозрачные стеклянные капсулы поверх интерфейса с пружинной анимацией при изменении:
  - Громкости и Mute (с показом подключённых Bluetooth-наушников)
  - Яркости экрана
  - Индикаторов **Caps Lock / Num Lock / Scroll Lock**
  - Уровня заряда Bluetooth-устройств
  - Смены играющего трека
  - Статуса **Микрофон ВКЛ / ВЫКЛ**
  - Живого пульсирующего **таймера записи экрана**

### 9. Реалистичные 2.5D-обои Oxygen 1.7 + Новая 60 FPS мини-игра с выбором
- Добавлены флагманские реалистичные 2.5D-обои **Oxygen 1.7 · Cryo-Bubbles (O-8)** (`public/luma-oxygen-hero.jpg`) при 100% сохранении всех 20 предыдущих обоев (**21 встроенный арт в галерее**).
- В пасхалке (**Настройки → Ядро UI → карточка Oxygen 1.7**) добавлена новая быстрая, не лагающая и запоминающаяся 60 FPS мини-игра **«Oxygen Pulse · O-8»** (Cryo-Orbital Synth на чистом Canvas 2D с WebAudio-синтезатором, комбо и Крио-импульсами) и удобный переключатель между новой и старыми играми: **✨ Новая: Oxygen** | **Старая: Арена** | **Старая: Орбита**.

### 10. Компаньон Oxygen Connect для Android (HarmonyOS SuperHub / Device+)
- В ядро встроен локальный LAN-сервер **Oxygen Connect** (порт `49218`) и чистый офлайн-генератор **QR-кода** (без интернета и сторонних сервисов).
- Откройте **Oxygen Connect** на ПК (Панель задач / Папка Luma / Панель управления) → отсканируйте QR-код на Android-смартфоне в той же Wi-Fi сети:
  - **Камера → ПК**: сделайте фото камерой смартфона — снимок мгновенно прилетит на ПК и автоматически попадёт в **Полку Dropzone**.
  - **Двусторонняя передача файлов** между Android и Windows.
  - **Общий буфер обмена** (Телефон ↔ ПК в 1 нажатие).
  - **Виртуальный тачпад, клавиатура и медиа-пульт** (громкость, пауза, переключение треков).
- В репозиторий также добавлен готовый нативный Kotlin-проект для Android Studio: [`LumaOxygenConnect_Android/`](LumaOxygenConnect_Android/).
