# Launcher Hab 2.4

Современный лаунчер на **Python + Flet** с настоящим эффектом прозрачного матового стекла (**Glassmorphism 2.4**), плавной анимацией переходов, фоновым контроллером системного звука, расширенным **Plugin API 2.4** и встроенным трекером игрового/экранного времени **Game & App Session Tracker**.

## Что нового в версии 2.4

- **Настоящий эффект прозрачного стекла (Glassmorphism 2.4)** — аппаратное размытие `ft.Blur`, тонкие стеклянные грани и настраиваемая прозрачность с сохранением фирменного стиля программы.
- **Плавные переходы между разделами** — анимация смены разделов («Приложения» ↔ «Трекер времени»), категорий и результатов поиска через `ft.AnimatedSwitcher`.
- **Улучшенное окно «Добавить приложение»** — живое превью стеклянной карточки, поиск по 70+ иконкам, автоопределение типа (Веб / Локальное EXE), аргументы командной строки и настройка дневного лимита.
- **Фоновый контроллер громкости системы** — работа в отдельном фоновом демон-потоке через `pycaw` / Windows CoreAudio COM (а также `pactl`/`amixer` на Linux и `osascript` на macOS) без зависаний и спама эмуляцией клавиш.
- **Плагин «Game & App Session Tracker» (Трекер активности и игрового времени)**:
  - Отображение общего времени прямо в карточках приложений (например: `Steam — 42 ч в мес`).
  - Графики активности на **День**, **Неделю** и **Месяц** на отдельной вкладке и в окне плагина.
  - Группы цифрового детокса («Игры», «Соцсети и мессенджеры», «Медиа») с уведомлениями при превышении дневного лимита.
- **Расширенные настройки стилей часов** — 6 пресетов отображения (`Классический`, `Stacked`, `Минималистичный`, `Стеклянная капсула`, `Цифровой моно`, `Компактный`), переключатели секунд, дня недели, стеклянной рамки и быстрые цветовые палитры.
- **Улучшенный Plugin API 2.4** — поддержка хуков `on_load(api)`, `on_app_launched(app)`, `on_tick()`, `get_app_card_badge(app)` и генератор шаблонов расширений прямо в интерфейсе.

## Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
